# 麦当劳省钱决策官（mcd-saver）

> 2026 麦当劳程序员创意开发大赛参赛作品 · WorkBuddy Skill
>
> 不替你点单，只替你**算清楚**：这单到底多少钱、哪套券最省、要不要等明天。

你看到的菜单价，和结账时付的钱，往往不是一回事。
本 Skill 用麦当劳官方 MCP 把两件事分开算：**标价（展示口径）** 和 **实付（结算口径）**，然后告诉你最优的那一套。

---

## 目标用户

| 用户类型 | 具体场景 | 本 Skill 给他的价值 |
|:--|:--|:--|
| **每天都在算的打工人** | 早餐/午餐固定点麦当劳，想看哪套组合最便宜 | 一次算清 3 套组合，直接给结论，不用自己在券包里翻 |
| **券包很满但没领的人** | 卡里躺着一堆券，不知道哪些能用、哪些已过期 | 先一键领齐，再校验"这家店这单"到底能用哪几张 |
| **对价格敏感的家庭用户** | 一单点三四样，几十块差价在意 | 真实计价避免"菜单看着便宜、结账贵一截" |
| **想薅活动但怕错过的人** | 不知道明天有没有更大的券，纠结要不要现在买 | 用活动日历算"等 vs 买"的差额，给出等多久的建议 |
| **积分快过期的人** | 想知道积分能换什么、值不值得花 | 查积分账户 + 商城可兑换项，给出兑换建议 |

不适合：只想"帮我下单、别废话"的用户（本 Skill 默认不下单，只给决策）。

## 快速开始

### 1. 申请麦当劳 MCP Token
访问 [https://open.mcd.cn/mcp](https://open.mcd.cn/mcp)，用**中国大陆手机号**注册，在控制台点「激活」获取 Bearer Token（免费）。

### 2. 配置 MCP 连接器

在 WorkBuddy 左侧栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置 MCP】，填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer 你的Token"
      }
    }
  }
}
```

保存后回到【自定义连接器】把它**启用**。
> 脱敏模板见 [`mcp-config.example.json`](./mcp-config.example.json)，其中只有环境变量占位符。
> ⚠️ Token 是私有的：只放在连接器配置里，**不要**写进任何文件、提交到仓库或发给他人。

### 3. 安装本 Skill

把本目录整体放进 WorkBuddy 的技能目录（`~/.workbuddy/skills/mcd-saver/`），新建会话即可生效。

## 使用示例

**问：帮我算下原味板烧鸡腿麦满分套餐加一杯可乐怎么点最省**

Skill 会依次做：取时间 → 定位门店 → 拉菜单 → 领券 → 查门店可用券 → 逐套组合真实计价 → 查活动日历，输出：

```
【麦当劳省钱结论】
你想要的：原味板烧鸡腿麦满分套餐 ×1 + 可乐 ×1

菜单展示价：¥23.60   ← 注意：14.1 那个价依赖"随单购早餐卡"
真实实付（无券）：¥33.00
差额：¥9.40

✅ 建议：当前无可用券（券包里没有已领券），实付 ¥33.00
   若愿意先领券再算，可再跑一次；门店券与麦麦省券叠加通常还能再降
⏰ 提示：10-08～10-21 有「9.9 元早餐两件套」活动，若只是想吃饱，
   改点两件套可能比这套组合更划算
```

> 上面的数字是 **2026-10-17 09:36 的真实调用结果**，不是示意数据。

**问：明天有大促吗？现在下单还是等等**
→ 调 `campaign-calendar` 看未来 48 小时活动，给出"等 X 小时可多省 Y 元"或"现在就买已是当前最优"。

**问：我有多少积分，能换什么**
→ 调 `query-my-account` + `mall-points-products`，给出可兑换清单与建议。

## 为什么它比"看菜单"更准

| 层 | 是什么 | 数据来源 |
|:--|:--|:--|
| **标榜层** | 菜单展示价、"满减"标语、带"随单购""早餐卡专享"标签的价格 | `query-meals` |
| **事实层** | 叠加券之后、结算系统真正认的金额 | `calculate-price` |

实测遇到过的真实落差：菜单显示 ¥14.1 的套餐，不随单购卡时结算 ¥23.5，**差 9.4 元**。
这类差价靠"看菜单"永远发现不了，只能靠真实计价。

## 安全设计

- **Token 不出 Skill**：只在连接器配置里，Skill 不读、不存、不打印、不写日志。
- **不下单**：默认只给决策。`create-order`、`mall-create-order`、`party-order-create`、`draw-lottery` 属资金动作，必须用户确认完整明细后才可调用。
- **隐私最小化**：地址类工具仅在用户明确要外送时调用，不做任何持久化。
- **不编造**：取不到实时数据时明确说"无法实算"，绝不拿标价冒充实付。
- **不夸大**：算出来省多少就写多少，不虚报优惠。
